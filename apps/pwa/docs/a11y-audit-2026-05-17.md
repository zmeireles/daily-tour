## Findings fixed

### F-1: Slider — invalid ARIA attributes on container + missing thumb label (serious)

**Rule:** `aria-allowed-attr`, `aria-input-field-name`  
**Component:** `components/range-slider.tsx` → `components/ui/slider.tsx`

**Root cause:**  
`RangeSlider` was passing `aria-valuemin`, `aria-valuemax`, `aria-valuenow`, `aria-valuetext` directly to the `Slider` root element. Radix UI renders the root as a plain `<span>` (no implicit ARIA role), so these attributes were invalid. Separately, the `<span role="slider">` thumb had no accessible name — axe flagged it under `aria-input-field-name`.

**Fix:**

1. `components/ui/slider.tsx` — added optional `thumbAriaLabel` prop forwarded to `SliderPrimitive.Thumb` as `aria-label`.
2. `components/range-slider.tsx` — removed the four invalid root-level ARIA props; switched to `thumbAriaLabel="Distance: {n} km"` so the label lands on the thumb element that actually has `role="slider"`.
