### DNS / domain

- Hostname layout (driven by `TRAEFIK_DOMAIN_BASE=qual.<sub>.portugalodyssey.pt`):
  - **apex** `qual.<sub>.portugalodyssey.pt` → guest PWA (label tweak: PWA answers apex, not `app.`)
  - `api.qual.<sub>…` → BFF · `auth.qual.<sub>…` → Authentik · `traefik.qual.<sub>…` → dashboard (basic-auth)
- TLS: **Let's Encrypt HTTP-01 per-host** (4 hostnames; avoids sharing PO's Cloudflare API token; the repo's staging resolver already does HTTP-01 — add a production resolver). Cloudflare records **DNS-only (grey cloud)** so ACME HTTP-01 and WS pass through untouched.

### Repo deploy surface — what exists vs gaps (full inventory: repo-deploy-recon, 2026-06-12)

Exists and is reusable: overlay compose model with healthchecks + `:?` env contract; Makefile `ENV=qual` plumbing (`.env.qual` → project `dt-qual`); Traefik overlay with ACME-staging resolver; Authentik overlay + owner-app blueprint; idempotent migrations (drizzle ×3, raw SQL ×3) and seeds orchestrated by `dev-up.sh` stages 4–5; `dev-smoke.sh` runs entirely over the internal network (VPS-friendly); `dev-env-check.sh` as a post-deploy gate; `DEPLOYS.md` ready for entries.

Gaps the plan closes (numbers = repo-recon gap list): no deploy workflow/GHCR images (1); no `.env.qual` (2); TLS unwired — all routers on `web`, no prod resolver, ACME email env-interpolation in static YAML is broken (3); Traefik bound to `127.0.0.1:27080/443` (4); **PWA same-origin routing** — `/v1`, `/r`, chat WS and media img-srcs are same-origin fetches, so the apex host must path-route them to the BFF with priority over the SPA router (5); `VITE_AUTHENTIK_URL` baked at PWA build time (6); blueprint redirect-URIs hardcoded (7); `NODE_ENV: development` hardcoded (9); `OSRM_URL` default points at non-existent `osrm-routed` (10); `02-roles.sql` placeholder DB passwords must be rotated pre-deploy (12); migrate/seed tooling needs host Node 22 + pnpm 9 (13); `acme.json` perms (14); no runner provisioning (16).

Out of scope for qual MVP (YAGNI until needed): n8n overlay (8), observability overlay (Grafana/Prometheus), OTel backend (11), SMTP/notif delivery (15). OSRM **is** in scope (Plan-002 exit criteria want real travel times).

## 4. Risk register

| Risk                                           | Mitigation                                                                                                      |
| ---------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| OOM on 8 GB box (Authentik+Postgres+12 svcs)   | mem_limits in qual overlay; 4 GB swap; observability overlay stays off                                          |
| Deploy job contends with stack (2 vCPU)        | runner concurrency 1; deploy = pull+up only (no builds); GHCR builds off-box                                    |
| ACME rate limits during bring-up               | staging resolver first; flip to prod only after routing verified                                                |
| Authentik blueprint silent-fail on 2026.2.2    | known quirk; manual fallback documented in `infra/authentik/README.md` + `temp/authentik-setup.py` pattern      |
| island-chronicles accidental data loss         | stop-not-down; tar backup on box + off-box copy **before** anything else; never touch `/root/island-chronicles` |
| Stale stack auto-resurrects on reboot          | it can't (`unless-stopped` + explicit stop persists) — verify after first VPS reboot anyway                     |
| PWA same-origin breakage (chat WS, media imgs) | apex path-routers `/v1`+`/r` with WS headers; smoke covers WS + media display                                   |

Apex pattern: `qual.<sub>.portugalodyssey.pt` (qual) → `<sub>.portugalodyssey.pt` (prod later). PO brand voice: plainspoken, PT-flavored, hospitality.

| `<sub>`                | Qual apex                         | For                                                                                                         | Against                                                |
